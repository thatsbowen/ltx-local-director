LTX 本地导演台 · 使用说明
==========================

【一、这是什么】
一个解压即用的 Windows AI 视频客户端。视频和声音都由你本机的显卡生成，
不联网、不需要账号、不上传任何数据。

支持：文生视频、图生视频、首尾帧、同步音频。

【二、开始使用】
1. 把整个 ZIP 解压到有写入权限的文件夹，例如 D:\LTX。
   不要放在 C:\Program Files，那里通常不允许写入。
2. 双击「LTX 本地导演台.exe」。
3. 首次启动会引导三步：
   - 检测显卡与显存
   - 按显存选择档位（8G / 16G / 24G / 32G / 64G）
   - 检查模型是否齐全
4. 模型不随程序包提供。按「README.md」里的清单把模型文件放进
   data\comfyui\models 对应子目录，然后点「重新扫描」。
5. 模型齐全后点「进入创作台」。

提示：「无需安装」不等于「无需下载」。程序包约 4GB，模型约 26GB。

【三、快速创作】
1. 在创作台选择模式：文生视频 / 图生视频 / 首尾帧。
2. 写下画面描述，例如：
   “清晨的窗边，一杯热咖啡冒着白气，镜头缓慢推近，柔和自然光。”
3. 需要时上传首帧、尾帧图片。
4. 选择分辨率、时长；采样步数固定为 9 步，不需要改。
5. 点「开始生成」。任务会在后台排队执行，可以离开页面。
6. 生成完成后自动归档到 data\videos\。

【四、成片在哪里】
- 成片：data\videos\（mp4，h264 视频 + aac 音频）
- 输入素材：data\assets\
- 运行日志：data\logs\
- 在「设置 → 本地数据」可以一键打开这些目录。

【五、档位与耗时】
- 16GB 档实测（RTX 5060 Ti，960×544，4 秒）：
  T2V 约 101 秒，I2V 约 91 秒，首尾帧约 99 秒。
- 首次生成需要额外约 70 秒加载模型。
- 分辨率比时长更贵：加一档分辨率约 +44%，加 1 秒约 +12%。
- 显存不足时优先降低分辨率，而不是缩短时长。

【六、模型放在哪】
data\comfyui\models\ 下按类型分目录：
  unet\            主模型（LTX-2.3-distilled-Q4_K_S.gguf）
  text_encoders\   文本编码器与投影层
  vae\             视频 VAE 与音频 VAE
  loras\           可选 LoRA
  其他可选模型见 README.md

文件名必须与清单完全一致，否则扫描不到。

【七、数据备份与更新】
- 所有历史、素材、设置都在 exe 同目录的 data\ 文件夹。
- 更新版本：先关闭应用，解压新 ZIP 覆盖程序文件，保留 data\ 文件夹。
- 建议定期把 data\ 文件夹复制到其他位置备份。

【八、常见问题】
Q：启动后提示缺少模型？
A：到「设置 → 模型清单」查看缺失项，按文件名放进对应目录后重新扫描。

Q：引擎启动失败？
A：到「设置 → 本地引擎」确认 ComfyUI 程序目录、模型根目录和 Python
   解释器路径正确；端口默认 8188，被占用时可改成其他端口。

Q：生成很慢或显存不足？
A：降低分辨率档位，或关闭其他占用显卡的程序。16GB 显存基本跑满，
   降低分辨率比缩短时长更有效。

Q：视频没有声音？
A：确认生成时「同步音频」是开启的，并且音频 VAE 模型已就位。

Q：Windows 提示“未知发布者”？
A：应用未做代码签名，点“更多信息 → 仍要运行”即可。

Q：程序目录不能写入？
A：应用会自动改用用户目录保存数据，实际路径可在「设置 → 本地数据」查看。

Q：特效转换为什么是灰的？
A：v1.0 暂未开放。现有 IC-LoRA 权重为 19B 版本，与当前 22B 主模型的
   兼容性仍在验证，验证通过后会随更新开放。

【九、隐私】
无登录、无云端同步、无行为统计。生成阶段只与本机 127.0.0.1 上的引擎
通信。唯一的联网行为是你主动发起的模型下载。
